# ⚔️ Blade Clash

A browser-based sword fighting game built with **React, TypeScript and Vite**.

## 🎮 Overview

**Blade Clash** is an interactive web-based fighting game focused on sword combat and responsive gameplay. The project combines a component-based React interface with TypeScript game logic to create an engaging browser gaming experience.

## ✨ Features

* ⚔️ Interactive sword fighting gameplay
* 🗡️ Multiple sword mechanics
* 🎵 Game sound effects
* 🏆 High-score tracking
* 🎨 Responsive game interface
* ⚡ Fast development and build workflow using Vite
* 📱 Browser-based gameplay

## 🛠️ Tech Stack

* **Frontend:** React
* **Language:** TypeScript
* **Build Tool:** Vite
* **Styling:** CSS
* **Development:** Visual Studio Code
* **Version Control:** Git & GitHub

## 🚀 Running the Project Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project:

```bash
cd Blade-Clash
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
